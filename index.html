NeggSweeper Solver

Shows which neggs are safe on the real game page. It works out the exact odds on every negg and never clicks anything for you. Runs entirely in your browser.

Source & notes on GitHub ↗

Set it up once

  1. Drag this orange button up to your bookmarks bar.
    No bar? Press Ctrl+Shift+B.
    NeggSweeper Helper
  2. Open NeggSweeper.
    Open the game ↗
  3. On the game page, click the bookmark once. It keeps working after every click, every win and every new game until you close the tab.

How it works

The bookmark reads the board straight off the page after every click. For every way the bad neggs could be hidden that fits all the numbers and the game's Remaining counter, it counts how often each negg is bad. A negg that is never bad is safe; one that is always bad is a bad negg. When no negg is safe, it marks the one least likely to be bad.

The card in the corner can also print the chance on every covered negg. The × on the card puts the game back to normal.
